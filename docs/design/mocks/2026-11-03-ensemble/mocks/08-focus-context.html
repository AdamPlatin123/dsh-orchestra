方案 08：焦点+上下文（鱼眼树）返回画廊
↑↓←→在塔里走Enter进入对话Esc回到你
图例
方案说明

隐喻：鱼眼镜头下的塔。焦点那条祖先链放到全尺寸，竖着叠成脊柱；脊柱每一段是一条双车道，左道往下送活，右道往上送回报和请求。离焦点越远越小，最后只剩一个诚实的数字。

脊柱 + 刻度你 → 焦点的祖先链，全部写名字；左边刻度写第几层
左道 ↓派活：谁派的、几点、任务首句、上下级往来几条
右道 ↑回来的东西：回报包裹（缺角＝截断）、等你的琥珀线、出错、还没回报的点线
名牌 / 短牌 / 方点兄弟离焦点的远近；方点角上的红、琥珀点是它下面有出错、等你
+N 和分段条折起来的兄弟；分段条是它们的状态构成，点开就是那 N 行

重押：P6 一次只展开一条祖先链（5 层不缩进不横滚）；P7 折叠诚实（分项之和等于总数）；P5 合作画成车道上的事件（派、回报、等待各有画法和时间）；P3 等你沿右道冒泡到「你」，队列里带来路、就地处理。

弱化：P1 全局工作线只在焦点停在「你」时完整出现，顶栏只留「以来」计数；P12 离开超过 5 分钟回来时自动回到「你」。

张力站位（第 5 节十对）：

  1. 合作可感 vs 安静：偏安静。合作只画在脊柱的车道上和焦点的子行里，焦点外不画任何动态。
  2. 空间 vs 列表：空间为主，但等你的事用一条按截止排序的列表，药丸点开就地处理。
  3. 全局 vs 焦点：焦点优先。全局只在「你」这一层出现。
  4. 实时 vs 稳定：稳定优先。兄弟和子行都按固定的原始顺序，等你、出错靠描边和角点突出，至多放大一档，不换位置；队列变化后 750 ms 内批准无效。
  5. 丰富 vs 贫瘠：两态同一套画法；贫瘠态按 7.4 的形状构造，斜纹方点占多数，不假装知道。
  6. 诗意 vs 说人话：隐喻只在这段说明里，界面全用「等你、出错、已回报」。
  7. 深度 vs 宽度：深度靠竖排，不吃宽度；1024 宽也不横滚。
  8. 压缩 vs 进入对话：默认压缩，Enter 一步进入自有会话的对话页。
  9. agent 主动 vs 人是权威：agent 的话只以署名引语出现；回报的状态位只放守护进程给的状态，没有就写未知。
  10. 只读 vs 自有：只读是空心框，没有批准、发消息、中断按钮，只留本机进程层面的刹车（键入确认）。

最弱的一点：焦点外的方点要走过去才知道是谁；贫瘠态里车道大多是虚线加「状态未知」，合作感在今天的数据上几乎为零，只能诚实地空着。
